## 4. 分阶段施工

### 阶段 1：建立护栏

- [ ] 补充领域根包、公开契约和 `allowedDependencies`。
- [ ] 增加 `ApplicationModules.verify()` 结构测试。
- [ ] 建立 Javadoc 基线，补齐本阶段新增或修改代码的注释。

### 阶段 2：收口公开能力

- [ ] 由能力拥有方定义 `Api / Command / Query / Result / Event`。
- [ ] 在边界完成 Req/Resp、旧 DTO、供应商对象到领域对象的转换。

### 阶段 3：迁移实现与数据访问

- [ ] 按能力切片移动 application/domain/infrastructure 实现。
- [ ] 将 Dao/Repository 和表写入收口到唯一拥有领域。
- [ ] 消除跨域内部包、Entity、DO、Mapper 依赖。
- [ ] 验证事务、幂等、事件投递与补偿。

- [ ] 调用方全部切换到新公开契约。
