# 飞书项目管理多维表格

## 固定入口

- 文档地址：`https://ccn0lyo7iuwk.feishu.cn/wiki/WEzRwFLKAit9BEk6OcDcYegznQg?table=tblfZgK5qdJDyacA&view=vewpI8lyYw`
- 目标菜单：`项目管理` 下的 `②版本开发计划`
- 常用视图：`各版本核心需求`
- 常见字段：`任务描述`、`优先级`、`任务执行人`、`迭代`、`PRD`、`进展`、`备注`

飞书内容依赖用户登录态。需要读取或写入时，优先使用 Chrome/Computer Use 操作用户已登录的页面；不要用未登录的网页抓取结果替代表格内容。

## 工作流程

1. 打开或定位固定入口，确认页面标题是 `项目管理 - 飞书云文档`。
2. 确认左侧菜单选中 `②版本开发计划`，上方视图是 `各版本核心需求`。
3. 根据用户目标定位迭代分组，例如 `5.27.0`。不要只凭记忆判断分组记录数，写入前后都要看页面。
4. 如果用户说“先整理”“我先看一下”，只在聊天里整理任务草案，不写入表格。
5. 用户确认写入后，逐条新增记录。写完后确认分组记录数、总记录数和顶部 `已经保存到云端` 状态。
6. 最终回复用中文说明写入条数、目标迭代、关键字段默认值，以及是否已保存。

## 任务整理规则

- 如果表格没有单独的产品线字段，把产品线拼进 `任务描述`，格式为：`产品线 - 任务描述`。
- `迭代` 使用用户指定版本，例如 `5.27.0`。
- 用户未指定负责人时，`任务执行人` 留空。
- 新任务默认 `进展` 使用表格默认值，通常是 `未开始`。
- `优先级` 按用户要求设置；没有明确要求时，先给出草案让用户确认。常用口径：
  - 核心版本目标、支付能力、多端能力补齐、上线承诺：`高-P0`
  - 体验优化、验证场景、非阻塞优化：`中-P1`
  - 低风险补充项：`低-P2`

## 写入操作要点

- 每次操作 Chrome 前先获取最新窗口状态。
- 中文输入优先用系统剪贴板：`printf %s '文本' | pbcopy`，再在 Chrome 中 `Cmd+V`。`type_text` 对中文长句不稳定。
- 在分组底部点该分组内的 `+` / 空白新增行，粘贴 `任务描述`。这样通常会继承当前分组的 `迭代`、默认 `优先级` 和 `进展`。
- 逐行粘贴，不要一次性粘贴 TSV 或多行文本；飞书富文本单元格可能把多行都吞进一个 `任务描述`。
- 不要随手按 `Escape`；在这个页面上曾经导致 Chrome 焦点跳到其他标签页。
- 调整单选字段时，可以点单元格打开下拉，选择 `高-P0`、`中-P1`、`低-P2`；也可以在已聚焦单元格里粘贴精确选项文本。
- 如果误建了空白行，只有在确认它是本次误操作时才删除。可打开该行详情，点右上更多菜单，选择 `删除记录`。

## 验证清单

- 目标迭代分组的记录数按预期增加。
- 新增行的 `任务描述` 已包含必要产品线前缀。
- `迭代` 是用户指定版本。
- `进展` 是 `未开始` 或用户指定值。
- `优先级` 与整理草案一致。
- 未指定负责人时没有误填负责人。
- 顶部显示 `已经保存到云端`。

## 示例处理

用户给出：

```text
装修大师国际版
1. 优化国际版服务请求网络链路
2. 新增第四步模式与配色选择

迭代是 5.27.0
```

整理为：

```text
装修大师国际版 - 优化国际版服务请求网络链路
装修大师国际版 - 新增第四步模式与配色选择
```

确认后写入 `5.27.0` 分组，负责人留空，进展保持 `未开始`，再按确认过的优先级更新。
